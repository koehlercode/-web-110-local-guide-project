# Local Guide Webpage

A simple one-page local guide webpage created using HTML and CSS. The project highlights a local cafe and provides visitors with information about the location, atmosphere, and menu.

## Project Files

- `index.html` — Contains the webpage structure and content using semantic HTML.
- `css/styles.css` — Contains the styling for colors, fonts, spacing, typography, links, and page layout.
- `images/` — Contains the image used on the webpage.

This project was created to practice fundamental HTML and CSS concepts, including semantic HTML structure, headings, paragraphs, lists, links, images, typography, colors, borders, and padding.
